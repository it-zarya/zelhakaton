# 0001 — Карта — рисованная SVG-схема

← [[index]]

## Контекст

Игре нужна карта Зеленограда с 23 микрорайонами, поверх неё туман. Стенд — планшет на выставке, Wi-Fi не гарантирован, на разработку 6 часов.

## Решение

Карта — один SVG в стиле генплана: каждый микрорайон — `<path id="mkr-NN">`. Геометрию берём из OpenStreetMap и упрощаем, стиль задаёт Claude Design.

## Альтернативы

| Вариант | Почему не он |
|---|---|
| MapLibre / OSM-тайлы | нужен интернет или офлайн-тайлы; трудно сделать красиво и «чертёжно»; жесты карты (пан, зум) конфликтуют со стиранием |
| Гибрид (схема в игре, реальная карта на мобильной странице) | допустимо позже для маршрутов, на хакатон не нужно |

## Последствия

- Зоны проверки = SVG-пути: подсчёт очистки через маску, без геокоординат.
- На мобильной странице маршрута точки ставим на ту же схему; для навигации даём ссылку «Открыть в Яндекс Картах».

## Когда пересмотреть

Если понадобится навигация «я здесь» на мобильных маршрутах.
