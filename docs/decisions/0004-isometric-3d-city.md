# 0004 — Изометрический 3D-город вместо SVG-схемы

← [[index]] · заменяет визуальную часть [[0001-svg-map|0001]]

## Контекст

Первый прототип (SVG-схема «калька генплана») не понравился: выглядит как справочник, а не игра. Хотелось вида сверху «как в SimCity».

## Решение

Three.js, ортографическая камера (наклон 32°, азимут подбирается автоматически под экран). Здания из OSM (`tools/osm/build_city.py` → `public/city.json`) выдавлены по этажности, лес — инстансы конусов, вода/дороги/ж/д — плоские меши. При правильном ответе здания микрорайона **вырастают**. Туман остаётся 2D-canvas поверх; контуры зон проецируются камерой в экранные пиксели.

## Альтернативы

| Вариант | Почему не он |
|---|---|
| Нарисованная изометрическая картинка | статична, дома не растут, география выдуманная, зоны обводить вручную |
| Пиксель-арт SimCity 2000 | не нарисовать за вечер; можно приблизить шейдером позже |
| MapLibre fill-extrusion | перспективная камера, нужен тайловый стек, спорит с жестами стирания |

## Последствия

- Нужен WebGL на планшете; рендер только по изменению (не 60 fps вхолостую).
- `SVG-карта` (`public/map.svg`) остаётся источником полигонов зон и запасным видом.
- Задание Claude Design: не «калька», а палитра/материалы изометрического города — переписать [[../design-brief|бриф]].

## Когда пересмотреть

Если планшет не тянет WebGL: отключить тени (`renderer.shadowMap.enabled = false`), затем деревья.
