# 0002 — Vite + TypeScript без UI-фреймворка

← [[index]]

## Контекст

Один полноэкранный интерактив с canvas и SVG, несколько экранов, контент в JSON. 6 часов разработки.

## Решение

Vite + TypeScript, экраны — модули, которые рисуют DOM напрямую. Сборка — статический `dist/`.

## Альтернативы

| Вариант | Почему не он |
|---|---|
| React | основная работа — canvas и pointer-события, где React не помогает, а цикл рендера мешает |
| Чистый HTML без сборщика | нет TS и удобного dev-сервера для проверки на планшете по сети (`--host`) |

## Последствия

Состояние игры — простой объект и функция `render(screen)`; не разрастаться.

## Когда пересмотреть

Если экранов станет больше 10 или появится сложная форма.
