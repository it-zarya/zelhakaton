# 0005 — Выкатка: сборка и проверка на ноутбуке, затем rsync

← [[index|Решения]] · [[../deploy|Выкатка]]

**Статус:** принято · **Дата:** 2026-09-26

## Контекст

Хакатон, прод уже поднят (nginx на своём сервере, статика). Нужна выкатка «через тест на локальном компе», и быстро.

## Рассмотрели

- **А. GitHub Actions** — сборка и заливка по push в `main`. Надёжнее для команды, но нужен деплой-ключ в секретах и ~20 минут настройки.
- **Б. rsync с ноутбука** — ✅ выбрано.
- **В. Сервер сам тянет из git** — нужен Node на сервере, хрупко.

## Решение

Б: `npm run release` собирает, поднимает собранную версию локально, гоняет автопроверку, ждёт ручного «y» и копирует `dist/` на сервер. Самый быстрый путь, и в прод едет ровно та сборка, которую проверили.

## Последствия

- Катить можно только с машины, где есть SSH-доступ к серверу.
- После хакатона при развитии проекта — перейти на А (GitHub Actions).
