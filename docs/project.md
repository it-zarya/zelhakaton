# О проекте

← [[index]]

## Что это

Интерактивный стенд для выставки об архитекторе **Игоре Александровиче Покровском** (1926–2002), главном архитекторе Зеленограда с 1964 по 2002 год.
Стенд — веб-сайт на **горизонтальном планшете** с игрой **«Сотри туман»**: на схеме города лежит туман, посетитель стирает его пальцем и так узнаёт, в каком порядке строился Зеленоград. Каждое открытое здание — карточка с фактом и QR-кодом, который уносится на телефон.

Геймплей подробно: [[gameplay]]. Дизайн: [[design]].

## Для кого

- Посетители выставки: семьи, школьники, жители Зеленограда 40+ (многие жили в этих домах).
- Жюри культурного хакатона.

## Глоссарий

| Термин | Значение |
|---|---|
| Мкр | микрорайон; в Зеленограде адрес — «корпус NNN», где первые цифры = номер мкр (корп. 360 → 3-й мкр) |
| Этап | один шаг игры: период застройки + зона на карте + здания-награды |
| Туман | слой поверх карты, который стирается пальцем |
| Карточка | всплывающая панель здания: фото, подпись, факт, QR |
| Режим экскурсии | просмотр без игры: весь туман снят, карточки кликабельны |
| Attract-режим | заставка при бездействии, приглашает коснуться экрана |
| «Флейта» | корп. 360, длинный жилой дом на опорах, единственный нетиповой жилой дом города |
| «Яйцо Покровского» | прозвище винтовой лестницы в КЦ «Зеленоград» (в исходниках путаница, см. [[content]]) |
