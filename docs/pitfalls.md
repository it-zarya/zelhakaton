# Грабли

← [[index]] · связано: [[architecture]], [[content]]

Известные заранее риски киоска на планшете. Подтверждённые на практике — пометить датой.

| Симптом | Причина | Что делать | Когда нашли |
|---|---|---|---|
| Факты в исходниках противоречат друг другу | тексты сгенерированы LLM | всё сверять, см. [[content]] | 2026-09-25 |
| Фото с PastVu/zelenograd.ru на экране | права у авторов, не CC | только Commons или с разрешения; иначе QR-ссылкой, см. [[research]] | 2026-09-25 |
| Стирание дёргает страницу, срабатывает pull-to-refresh или зум | браузер обрабатывает жесты | `touch-action: none` на карте, `overscroll-behavior: none` на body, `user-scalable=no` | ожидаемо |
| Мышью в браузере работает, пальцем нет | использованы `mouse*`-события | только Pointer Events (`pointerdown/move/up`) + `setPointerCapture` | ожидаемо |
| Планшет гаснет / блокируется на стенде | системный таймаут экрана | отключить сон в настройках планшета; Wake Lock API как дополнение | ожидаемо |
| Посетитель вышел из браузера | нет киоск-режима | Android: закрепление экрана (screen pinning), iPad: Гид-доступ (Guided Access) | ожидаемо |
| Подсчёт очистки тормозит | `getImageData` на полном канвасе каждый кадр | считать по уменьшенной маске, не чаще ~300 мс | ожидаемо |
| Размыто на Retina | canvas без учёта `devicePixelRatio` | размер буфера = CSS-размер × DPR | ожидаемо |
| Шрифты или картинки не грузятся на площадке | нет Wi-Fi, ассеты с CDN | всё локально в `public/` | ожидаемо |
| QR на экране не открывается на телефоне | ссылка на `localhost` / IP планшета | QR только на публичный хостинг | ожидаемо |
