## Git

- Один репозиторий, ветка `main`, коммит после каждого рабочего шага: на хакатоне откат важнее красивой истории.
- Сообщения коммитов по-русски, коротко: `туман: подсчёт очистки зоны`.

## Definition of Done

- Проверено **на планшете пальцем**, а не мышкой в браузере.
- Текст на экране есть в [[content]] со статусом ✅.
